# Visualization - Flickr Lyon Map

## Summary

Interactive Folium map displaying geo-located photos from Lyon.

## Features

- **Marker Cluster**: 5,000 clickable markers with photo info
- **Layer Control**: Toggle between map styles

## Output

- File: `outputs/lyon_map.html` (~8.7 MB)
- 72,606 data points visualized



## Marker Popup Info

Each marker shows:
- Photo ID
- User
- Date taken
- Tags (first 100 chars)
- Link to Flickr
